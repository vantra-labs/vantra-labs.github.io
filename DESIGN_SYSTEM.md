# VANTRA — дизайн-система сайта

Статус: **принято.** Сайт свёрстан по этому документу в ветке `site-v3`.

## 1. Что делает сайт

Сайт студии, на котором продукты стоят впереди студии.

- Главная задача: человек понял, что такое Actum, и скачал его.
- Вторая задача: увидел, что у студии есть второй рабочий продукт, Clarify.
- Студия — рамка вокруг продуктов, а не отдельная витрина. Пустых разделов «под кейсы» нет.

Режим поверхности: **Persuade** (лендинг). Страницы политик: **Read**.

## 2. Главная идея

**Документ на графите.** Actum делает бумагу: акты, реестры, комплекты. Поэтому на сайте единственное светлое пятно — лист А4, вынутый из приложения. Всё остальное графит и тишина. Лист — то самое одно запоминающееся место, вся смелость уходит в него.

Чего избегаем сознательно:
- тёплой «бумаги» фоном всей страницы (текущий сайт, самый заезженный AI-шаблон);
- одинаковых скруглённых карточек с тенями на каждом блоке;
- появления каждого блока с подъёмом при прокрутке;
- капса с разрядкой в подписях, моноширинных «технических» меток, стрелок «→» в кнопках;
- синего у Actum.

## 3. Цвет

Сайт **только тёмный**, графит. Это цвет бренда и тёмная тема обоих приложений. Одна тема — вдвое меньше проверки и ни одного места, где скрин приложения спорит с фоном.

| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#121110` | Фон страницы (тёплый графит, как фон Actum) |
| `--bg-raised` | `#1B1A18` | Приподнятые зоны: полоса продукта, подвал |
| `--surface` | `#232120` | Редкие контейнеры: блок установки, FAQ |
| `--line` | `rgba(242,238,231,.10)` | Линии и разделители |
| `--line-strong` | `rgba(242,238,231,.20)` | Обводка вторичной кнопки, фокус-кольцо в покое |
| `--ink` | `#F2EEE7` | Основной текст и заголовки (16.3:1) |
| `--ink-2` | `#B4AC9F` | Вторичный текст (8.4:1) |
| `--ink-3` | `#8F887C` | Подписи, мета (5.4:1 на фоне, 4.95:1 на `--bg-raised`) |
| `--accent` | `#F2EEE7` | Главная кнопка: заливка — инверсия фона, как в приложениях |
| `--on-accent` | `#121110` | Текст на главной кнопке |
| `--sheet` | `#FFFEFB` | Лист документа. Единственная светлая плоскость на сайте |
| `--sheet-ink` | `#1E1C19` | Текст на листе (16.9:1) |
| `--warn` | `#F0C06A` | Только предупреждение про SmartScreen (11.2:1) |

Правила:
- Цвет появляется только там, где что-то значит: предупреждение и скрины самих приложений.
- Минимум контраста 4.5:1 для любого текста. `--ink-3` не ставится на `--surface`.
- `color-scheme: dark`, `theme-color` = `--bg`.

## 4. Шрифты

| Роль | Шрифт | Настройка |
|---|---|---|
| Заголовки и интерфейс | **Geologica** (variable) | 600–700, трекинг от −0.03em на крупном до 0 на мелком |
| Текст | **Golos Text** | 400/500/600, трекинг 0 |

Почему так:
- Geologica — шрифт интерфейса самого Actum. Сайт и приложение говорят одним голосом.
- Оба шрифта рисовались под кириллицу, а не дорисовывали её к латинице.
- Golos Text уже лежит на сайте, его меняем только по роли.
- Unbounded уходит: широкий гротеск на каждом заголовке и делал сайт похожим на тысячу других.

Шкала (`rem`, растёт через `clamp`):

| Уровень | Размер | Интерлиньяж |
|---|---|---|
| Display (только первый экран) | 2.75 → 5rem | 1.0 |
| H2 | 2 → 3rem | 1.08 |
| H3 | 1.25 → 1.5rem | 1.2 |
| Текст крупный | 1.125 → 1.25rem | 1.55 |
| Текст | 1rem | 1.6 |
| Подпись | 0.875rem | 1.45 |

- Длина строки текста до 64 знаков, заголовков до 20.
- Заголовки с `text-wrap: balance`, текст с `text-wrap: pretty`.
- Неразрывные пробелы после предлогов и в «40 МБ», «Windows 10».

## 5. Сетка и воздух

- Контейнер 1200px, поля `clamp(1.25rem, 5vw, 4rem)`.
- 12 колонок на десктопе, одна на телефоне.
- Шкала отступов кратна 8: 8 / 16 / 24 / 40 / 64 / 104 / 168.
- Между крупными разделами 104–168px. Воздух вместо линий: разделы разделяет пустота, линии только внутри списков.
- Выравнивание по левому краю. По центру только финальный призыв.
- Скругления: кнопки — таблетка, окна приложений — 12px, лист документа — 2px (это бумага).

## 6. Блоки

### Шапка
Прозрачный слой с размытием, контент уходит под неё. Вместо жёсткой линии снизу — мягкое затемнение, только когда страница прокручена. Ссылки: Actum, Clarify, Связь. Справа кнопка «Скачать Actum».

### Первый экран (Actum)
Слева заголовок, одна фраза пояснения, кнопка «Скачать для Windows» и строка «Версия 1.0.5 · Windows 10 и 11 · бесплатно в бете». Справа окно Actum на графите, из которого выезжает лист АОСР. Анимация одна на весь сайт и проигрывается один раз.

### Что умеет Actum
Не карточки, а три полосы во всю ширину: текст слева, живой скрин справа, через раз зеркально. Только то, что уже работает:
1. Импорт старых актов из Word.
2. Реестры и приложения собираются сами.
3. Готовый комплект одним PDF.

### Clarify
Одна широкая полоса на `--bg-raised`: знак, одна фраза, скрин тёмной темы, две кнопки. Визуально тише блока Actum.

### Студия
Короткий абзац о том, кто делает и зачем, и ссылка на Telegram-канал. Без правил-манифеста.

### Подвал
Две колонки ссылок, подписи колонок обычным регистром. Строки ссылок не ниже 44px.

### Страница /actum/
Первый экран, «как это работает» (4 шага, нумерация уместна: это последовательность), экраны, блок «До скачивания» с предупреждением SmartScreen, вопросы и ответы, повтор кнопки.

### Страница /clarify/
Структура сохраняется, она хорошая. Переходит на новые токены. Схема разбора фразы и блок SmartScreen остаются как есть по смыслу. Все скрины переводятся на тёмную тему.

## 7. Движение

Принципы Emil Kowalski и Apple:
- Одна постановочная анимация: лист выезжает из окна на первом экране, 700ms, `cubic-bezier(0.23, 1, 0.32, 1)`, один раз.
- Нажатие кнопки: `scale(0.97)`, 140ms.
- Наведение только при `@media (hover: hover) and (pointer: fine)`.
- При прокрутке проявляются только предметы (листы, окна): срез снизу вверх через `clip-path`, 900ms, один раз. Текст не двигается. Уже видимое при загрузке не прячется.
- Вкладки экранов на телефоне листаются пальцем через `scroll-snap`: лента идёт за пальцем 1:1 без скрипта, скрипт только сверяет активную вкладку.
- Наведение на стопку листов чуть раскрывает её, 450ms, только при точном указателе.
- Вопросы раскрываются по высоте там, где браузер это умеет (`interpolate-size`), иначе мгновенно.
- Анимируются только `transform` и `opacity`. Никакого `transition: all`.
- `prefers-reduced-motion`: лист сразу на месте, без движения.

## 8. Снимки приложений

Снимки делаются скиллом `clean-ui-shot` в стиле **glass**: градиент из цветов самого интерфейса и матовая рамка. На графите он не даёт светлого пятна. Только живые сборки и демо-данные, без реальных объектов и задач.

## 9. Компоненты и shadcn

Сайт — статический HTML на GitHub Pages, без React и Tailwind. Компоненты shadcn — это React-код, поставить их сюда нельзя без переезда сайта на Next/Astro. Переезд ради двух страниц без интерактива не окупается, поэтому не переезжаем.

Что берём у shadcn как образец, а не как код:
- **Семантика токенов:** фон, текст, приглушённое, граница, кольцо фокуса. Наши имена в §3 построены так же.
- **Button:** варианты `primary` и `outline`, размеры `md`/`lg`, иконка слева.
- **Separator:** одна линия `--line` вместо самодельных бордеров.
- **Accordion:** вопросы и ответы на `<details>/<summary>`, без JS.
- **Tabs:** переключатель экранов на странице продукта вместо карусели со стрелками.
- **Alert:** блок SmartScreen.
- **Badge:** «Бета», «Бесплатно».

## 10. Обязательный минимум качества

- Контраст текста ≥ 4.5:1, проверяется на каждом сочетании.
- Видимый фокус на всём нажимаемом.
- Цели нажатия ≥ 44px на телефоне.
- Skip-link, один `h1` на страницу, иерархия заголовков без пропусков.
- У картинок размеры и `alt`, ниже первого экрана — `loading="lazy"`.
- Шрифты свои, без сторонних серверов. Предзагрузка только начертаний первого экрана.
- Проверка в браузере на 390, 768, 1440px перед выкладкой.
- Скрины только из актуальных версий приложений.
